100s Base Zones

Label: City code zoning group

The 100 series contains the base zone chapters. These chapters state which uses are allowed in each zone. They also state which uses are allowed in limited situations, which are conditional uses, and which are prohibited. The general development standards for each base zone are also included. The development standards include requirements such as maximum heights and required setbacks.
